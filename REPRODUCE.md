# Reproducing the paper

This file takes a fresh clone to every table and number the paper reports. It has four parts:
[setup](#1-setup) (about 15 minutes, no data needed), [source data](#2-source-data),
[runs per instance](#3-runs-per-instance) and the [paper-to-table map](#4-paper-to-table-map).
Anything not yet scripted end to end is listed under [known gaps](#5-known-gaps).

**Reported runs were made on** Windows 10 (Git Bash), AMD Ryzen 7 9800X3D (8 cores), 64 GB RAM,
Oracle Java 21.0.1, Docker 29.4.3, with a new JVM per discovery run and an 8 GiB heap (12 GiB for
the full corpora). The scripts also target Linux and macOS, but the full pipeline has so far only
been run on Windows. Runtimes depend on hardware; result sets and counts should not.

**Disk:** the source corpora take about 36 GB (MusicBrainz 17 GB, IMDB 6 GB, Helsinki 5.5 GB,
ListenBrainz 5.3 GB, MovieLens 1.3 GB, TPC-H 1.1 GB) and `WORK_ROOT` about 20 GB once every instance
has been exported and discovered. TPC-H and UniBench alone need under 3 GB.

## 1. Setup

Requirements: Git, Bash (Git Bash on Windows), JDK 21, Maven 3.9, Python 3.10+, Docker with
Compose v2.17+.

```bash
git clone --recurse-submodules <repository-url> multi-model && cd multi-model
python -m pip install -r requirements.txt
python -m nltk.downloader wordnet
cp config/connections.properties.example config/connections.properties

./run.sh metanome         # installs the Metanome snapshots HyFD/HyUCC build against (once)
./run.sh build-upstream   # SPIND, HyFD-Partial, HyUCC-Partial, built in place
./run.sh build            # adapters, meta-level exporter, discovery runners
./run.sh test             # regression tests; should end with the union stress test output
docker compose up -d      # empty PostgreSQL 17, MongoDB 8, Neo4j 2026.03 on the default ports
```

Paths default to `data/` (source corpora) and `work/` (everything derived) inside the clone. To
put them elsewhere, create `config/paths.local.env`, for example:

```bash
DATA_ROOT=/mnt/corpora
WORK_ROOT=/scratch/multimodel
```

or set the variable for one command (`WORK_ROOT=/tmp/mm ./run.sh tables`). On Windows write paths
as `F:/corpora`, not `/f/corpora`, because they are passed to `java.exe`.

Two instances need external systems. Their checkouts are submodules under `upstream/` (fetched by
`--recurse-submodules`) and are set up by `scripts/setup-baselines.sh`:

| | needed for | command |
|---|---|---|
| ER'25 ([ref-seeker-extractor](https://github.com/dbishagen/ref-seeker-extractor)) | Tab. 5 ER'25 row, MMSBench-Net 3/9, ER'25 timings | `./scripts/setup-baselines.sh er25` |
| Polypheny benchmarking client | MMSBench-Net (generated by its `coms` scenario) | `./scripts/setup-baselines.sh polypheny` |

`baselines/er25/` documents the four changes the local ER'25 build makes (Python pin, CRLF repair
of its WordNet copy, a guard for attribute-less datastorages, build context) and why each is needed
to run the system at all. `baselines/polypheny/` holds the one-task patch that exports the client's
runtime classpath.

IMDB file names: `title.akas.tsv` → `akas.csv`, `title.basics.tsv` → `basics.csv`,
`title.crew.tsv` → `cew.csv`, `title.episode.tsv` → `episode.csv`, `name.basics.tsv` → `name.csv`,
`title.principals.tsv` → `principals.csv`, `title.ratings.tsv` → `rating.csv` (tab-separated,
`\N` for missing, header row kept).

IMDb and MusicBrainz publish rolling snapshots, so a download today will not match the
checksums. The instance sizes, oracles and recall should still be reproducible in kind; the
exact counts of Table 4 need the snapshot the manifests describe.

Check a snapshot with, for example, `(cd "$DATA_ROOT" && sha256sum -c "$OLDPWD/experiments/datasets/manifests/imdb.sha256")`.

## 3. Runs per instance

All commands run from the repository root and write below `$WORK_ROOT`. Java runners are called
through the shared classpath: `source core/adapters/build.sh` exports it as `$MM_CP` and compiles
first. Runs are independent across instances; within one instance, run the steps in order.

### TPC-H (seeded)

```bash
python experiments/datasets/build_dataset.py          # three stores from one TPC-H source
bash   experiments/datasets/load_stores.sh            # into the compose containers
source core/adapters/build.sh
java -cp "$MM_CP" -Dspind.connections="$MM_REPO/config/connections.properties" \
     ExportTpch "$(mm_path "$WORK_ROOT/mm_tpch/metalevel")"
bash experiments/run/run_all.sh "$WORK_ROOT/mm_tpch/metalevel" 1.0 "$WORK_ROOT/compare/mm-1.0"
java -Xmx8g -cp "$MM_CP" SpindMetaLevel "$(mm_path "$WORK_ROOT/mm_tpch/metalevel")" 0.95 \
     "$(mm_path "$WORK_ROOT/compare/mm-0.95-rerun/temp")" "$(mm_path "$WORK_ROOT/compare/mm-0.95-rerun/ind-results")"
bash experiments/run/scale_multimodel.sh 5000 10000 20000 40000 80000   # scaling series
```

### UniBench (third-party labelled)

```bash
(cd upstream/unibench-ind && DATA_SIZE=0.01 docker compose up -d)
python experiments/datasets/unibench_oracle.py        # external oracle, 34 dependencies
./ind/run-metalevel.sh 1.0                            # export, then exact INDs (scoped)
./ind/run-metalevel.sh 0.5                            # partial INDs (scoped)
./ind/run-unibench.sh 1.0 && ./ind/run-unibench.sh 0.5   # flat adapter, both thresholds
./fd/run-metalevel.sh 1.0 && ./ucc/run-metalevel.sh 1.0
python experiments/run/genuineness_sweep.py "$WORK_ROOT/unibench/metalevel" --threshold=1.0 --top=0
source core/adapters/build.sh
java -Xmx8g -cp "$MM_CP" SpindSimilarity "$(mm_path "$WORK_ROOT/unibench/metalevel")" 0.5 1 \
     "$(mm_path "$WORK_ROOT/unibench/temp")" "$(mm_path "$WORK_ROOT/unibench/p50-sim")"
python profile/genuineness.py "$WORK_ROOT/unibench/metalevel" "$WORK_ROOT/unibench/meta-results-0.5" \
     --json="$WORK_ROOT/unibench/genuineness-0.5.json"
python experiments/run/profile_calibration.py         # one knob per profile component
./scripts/setup-baselines.sh er25 && python experiments/run/er25_baseline.py
```

     "$(mm_path "$WORK_ROOT/movielens/temp-sim")" "$(mm_path "$WORK_ROOT/movielens/sim-prefix-0.5")"   # Tab. 4 footnote
java -Xmx12g -Dspind.maxValueLength=600 -cp "$MM_CP" SpindSimilarity "$(mm_path "$WORK_ROOT/hperson/metalevel")" 0.5 1 \
     "$(mm_path "$WORK_ROOT/hperson/temp-sim-t1")" "$(mm_path "$WORK_ROOT/hperson/sim-t1-0.5")"   #   likewise edit distance 1
